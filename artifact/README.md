# Artifact

This folder contains generated or associated artifact files for this workspace.

## Structure

- `models/`: archived agent outputs and model artifacts.
- `data/`: CSV result tables and final tabular summaries.
- `figures/final/`: final comparison, tree, star, and objective-bound plots.
- `figures/parallel/`: parallel performance, runtime, and score plots.
- `figures/tree/`: tree layout, performance, runtime, and score plots.
- `figures/general/`: shared runtime and score plots.
